개인정보처리방침

SVIL(Singularity Visual Intelligence Lab, 이하 "연구소")은 이용자의 개인정보를 중요하게 여기며, 관련 법령을 준수합니다.

1. 수집 항목

  • 문의하기: 문의 내용, 이름·이메일(이용자가 선택적으로 입력한 경우)
  • 회원 로그인(구글 계정): 이메일, 이름 — 로그인은 선택이며, 로그인 없이도 모든 기능을 이용할 수 있습니다
  • 접속 로그, 브라우저 정보, 방문 일시 (서비스 이용 과정에서 자동 수집)

2. 이용 목적

  • 문의 응대 및 서비스 개선
  • 회원 식별 및 관리자 기능 제공
  • 서비스 품질 분석 및 보안 관리

3. 보유 및 이용 기간과 파기

수집 목적을 달성하면 지체 없이 파기하며, 관련 법령에 따라 보관이 필요한 경우 해당 기간 동안만 보관합니다. 회원 탈퇴를 요청하시면 회원 정보를 즉시 삭제합니다.

  • 파기 시점: 목적 달성일, 탈퇴 요청일, 또는 법정 보관기간 만료일
  • 파기 방법: 전자적 파일은 복구할 수 없는 방법으로 영구 삭제하며, 출력물이 있는 경우 분쇄하거나 소각합니다

4. 제3자 제공

법령상 근거가 있는 경우를 제외하고 이용자 동의 없이 개인정보를 외부에 제공하지 않습니다. 연구소는 개인정보를 판매하거나 광고 목적으로 공유하지 않습니다.

5. 처리 위탁

서비스 운영에 필요한 범위에서 아래 사업자의 인프라를 이용합니다.

  • GitHub, Inc. — 홈페이지(정적 페이지) 호스팅
  • Railway Corp. — 문의·로그인 처리를 담당하는 백엔드 서버 호스팅
  • Google LLC — 구글 계정 로그인 인증

6. 구글 계정 연동과 Google API 이용

홈페이지의 로그인은 구글 계정 인증만 이용하며, 이때 연구소가 받는 정보는 이메일과 이름뿐입니다. 로그인은 선택이며 로그인 없이도 모든 내용을 보실 수 있습니다.

연구소는 이와 별도로 운영자 본인 계정에 한해 YouTube Data API 등 구글 API를 이용해 연구소 채널에 영상을 올리는 자동화 도구를 운영합니다. 이 도구는 이용자의 구글 계정에는 접근하지 않습니다.

연구소가 구글 API로 받은 정보의 이용과 다른 앱으로의 전송은 Google API 서비스 이용자 데이터 정책(제한적 이용 요건 포함)을 따릅니다. YouTube 기능을 이용하는 범위에서는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

7. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 아래 권리를 행사할 수 있습니다.

  • 열람 요구
  • 오류가 있을 경우 정정·삭제 요구
  • 처리 정지 요구
  • 동의 철회 및 회원 탈퇴 요구

아래 문의 이메일로 요청하시면 지체 없이 처리하고 그 결과를 알려 드립니다. 법정대리인을 통해서도 요청하실 수 있습니다.

8. 쿠키 등 자동 수집 장치

연구소는 광고·추적 목적의 쿠키를 사용하지 않으며, 외부 분석 도구도 홈페이지에 넣지 않았습니다. 다만 로그인 상태를 유지하기 위한 최소한의 쿠키·토큰을 사용합니다.

이 값은 브라우저 설정에서 거부하거나 삭제하실 수 있습니다. 거부하시면 로그인 기능만 이용할 수 없고, 나머지 내용은 그대로 보실 수 있습니다.

9. 안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화합니다
  • 개인정보에 접근할 수 있는 인원을 운영자 본인으로 최소화합니다
  • 인증 정보와 API 키는 소스 코드에 두지 않고 별도로 관리합니다

11. 방침의 변경

법령이나 서비스 내용이 바뀌어 이 방침을 고칠 때에는 변경 사항을 이 페이지에 게시하고 시행일을 함께 적습니다. 중요한 변경은 시행 최소 7일 전에 알려 드립니다.
